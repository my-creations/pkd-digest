# Privacy & analytics (v1)

**Decision:** no site analytics for PKD Digest / Digest DRP.

- No Plausible, Google Analytics, advertising pixels, or other third-party tracking scripts in the Eleventy layout.
- Documented for visitors on `/privacy/` (EN) and `/pt/privacy/` (PT).
- Preferred future option if metrics are needed later: **Plausible** (cookieless), only after an explicit product decision and a separate PR.

Hosting note: GitHub Pages / GitHub may still process infrastructure logs outside this repository.

This page is the short product policy; Dev2 legal PR may extend notices without changing the “no analytics” default unless product reopens the decision.
